# Terraform (IaC)

Este diretório contém um esqueleto de infraestrutura como código (Terraform) para fins acadêmicos.

## Objetivo
Demonstrar boas práticas de IaC: definição declarativa, versionamento e reprodutibilidade.

## Recursos (exemplo)
- Provider AWS
- VPC básica

## Observação
Não foi executado `terraform apply` para evitar custos em nuvem.
Os arquivos podem ser validados com `terraform init` e `terraform validate`.
